Wave 2 Implementation: Feedback Components, Calendar & DatePicker
- **Spinner**: Accessible, token-driven indeterminate loading indicator with configurable sizes (`xs`–`xl`), semantic color schemes, accessible name handling, and reduced-motion compliance.
- **Skeleton**: Content loading placeholder supporting multiple shapes (`text`, `circular`, `rectangular`, `rounded`), explicit dimensions, animation modes (`pulse`, `wave`, `none`), and loaded state toggle.
- **Progress**: Linear and circular progress indicators supporting determinate and indeterminate modes, accessible ARIA progress semantics (`aria-valuenow`, `aria-valuemin`, `aria-valuemax`), stripes, and animations.
- **Calendar**: Pure local-calendar date selection foundation with WAI-ARIA APG grid keyboard navigation, roving tabindex, leap-year and month boundary traversal, min/max limits, and disabled predicates.
- **DatePicker**: Composed popover input pairing Calendar with Popover, Input, and FormField integration, supporting controlled/uncontrolled selection, escape dismissal, focus restoration, and manual date input parsing.
